# Test 30-15 IFT · Registro en cancha

App web instalable para registrar en cancha el test 30-15 IFT por categoría. Funciona **sin internet** una vez instalada.

**Instalar en iPad/iPhone:** abrir el enlace de GitHub Pages en Safari → Compartir → "Agregar a pantalla de inicio".
**Instalar en Android:** abrir en Chrome → menú ⋮ → "Instalar app".

Los datos se guardan en el dispositivo. Descargar respaldo desde *Ajustes* al terminar cada jornada.
